3 内置命令 Command
3.1 调用方式
通过往记忆变量发送命令信号实现与平台内部服务的交互。
3.1.1 调用方式1：发送命令信号
	•	1） 组装命令信号JSON结构体
JSON {   // 命令编码, 必填   "command":"command code",   // 命令参数, 每个命令有它的参数结构，参考下文。如果没有参数就设置为{}   "data":{       // ....   },   // 是否异步调用，可不填。默认false.   "async": false }
	•	2）组装好的命令信号连接到记忆变量，记忆变量的key必须是$command_xxx开头。
	•	3）如果需要获取命令调用后的结果数据则使用以下方式获取：
{{记忆变量的key.result}}
示例：{{$command_mytext2agent.result}}

3.1.2 调用方式2：声明函数式调用
 声明命令函数：[$[ 命令数据JSON ]$] 
示例：
Python[$[    {       "command":"AddMessageMeta",       "embedResult": true, // true 会把命令结果嵌入到prompt所在位置。false则命令所在为之替换为空。       "data": {          "alias":"xxx",          "metadata":          {"renderType" : "deepResearchDesign", "toolType":"deepResearch"}        }    }]$]

3.2 命令列表
3.2.1 text2agent 创建Agent命令
命令参数：
JSON{   "command":"text2agent",   "data": {        // 编排数据        "agentJson":[]   }}
命令结果：
JSON{   "result": {        "avatar":"",        "id":"",        "intro":"",        "name":""   }}
3.2.2 userKbs 查询用户知识库列表命令
命令参数：
JSON{   "command":"userKb",   "data": {}}
命令结果：
JSON{  "result":[      {        "avatar":"",        "id":"",        "name":""      }  ]}
3.2.3 AddMessageMeta 消息携带元信息
命令参数：
JSON{   "command":"AddMessageMeta",   "data": {      "whenComplete": false,      "metadata": {"metaKey1" : "metaValue1","metaKey2" : "metaValue2"},      "beforeMetadata": {"metaKey1" : "metaValue1","metaKey2" : "metaValue2"},      "afterMetadata": {"metaKey1" : "metaValue1","metaKey2" : "metaValue2"}    }}
参数说明：
	•	流式输出增加字段: metaMessage 消息携带元信息，包含一些系统内置属性和用户自定义metadata:
	•	whenComplete 仅当某组件回复结束时携带元信息，默认fasle
	•	beforeMetadata 前置元数据,仅当某组件回复第一个token时携带的元信息，非必填；由用户自定义其内的属性和值;
	•	metadata 元数据,所有流式回复过程都携带的元信息，如果设置了whenComplete=true 则仅在流某组件回复complete时携带的元信息，非必填；由用户自定义其内的属性和值; 
	•	afterMetadata 后置元数据,仅当某组件回复complete时携带的元信息，非必填；由用户自定义其内的属性和值
命令结果：无

4 代码块嵌入
获取内置参数：params['yourVarNameToGet'] 可以取到当前记忆变量的值
需要有返回值：return yourVarNameToReturn 可以取到当前记忆变量的值，有返回值会嵌入到它所在位置
简单实例参考：5.2.1 章节
4.1 嵌入Python代码
示例：
Python我是:[python[name="邹鹏飞"return name]python]他是:[py[name="张三"return name]py]都来自国家：[py[import jsondata=json.loads(params['data'])return data['cou']]py]
4.2 嵌入JS代码
示例：
JavaScript我是:[js[name="邹鹏飞"return name]js]他是:[js[name="张三"return name]js]都来自国家：[js[data=JSON.parse(params['data'])return data['cou']]js]

5.3 知识库进阶 - 高级查询示例
知识库搜索组件的信息输入支持高级查询设置，支持分组并行召回、指定文件召回、不同分组不同权重和相似度设置等。
示例如下：
JSON{  "keywords": "2025年3月18日晚峰短信的内容是什么？",  "overwrite": "true",  // 可以固定指定，也可以通过{{$kbIdList}}获取用户选择的知识库ID列表动态指定  "kbIdList": [2,3,4,5,6],  "searchGroups": [    {      "kbIdList": [        5      ],      "topK": 22,      "fileNameKeywords": [        "特高压",        "运行规定"      ]    },    {      "kbIdList": [2,3,4,5,6],      "topK": 6    }  ]}
高阶查询字段解释说明
	•	keywords 查询关键词
	•	overwrite 是否覆盖知识库搜索组件选定的知识库，默认true, 如果为false,则会将知识库搜索组件选定的知识库与kbIdList合并

	•	topK 召回数

5.5 数据处理协议（v1.9.0.0+）
支持的组件有：确定回复、代码块、自定义组件的输出字段
实现方法：
将字段值组装为特定协议的数据结构
	•	schema 固定值schema-v1，系统用于识别该数据处理协议，以扩展实现不同的功能用途
	•	type 数据类型
	•	text：文本、markdown
	•	file：文件
	•	image：图片
	•	websearch：Web搜索
	•	needSendMessage 是否需要发送消息，true/false; 系统会根据数据类型发送对应的消息格式响应给终端用户
	•	needEncryptFileUrl 是否返回加密了文件流的下载地址，开启了加密服务的才生效。如果客户没有文件流加密服务，则加密服务需要定制开发。
	•	needFullFileUrl 是否返回文件下载地址的绝对路径，默认false(下载地址的相对路径)
	•	value 数据的值
	•	文本类型直接赋值字符串值即可
	•	文件和图片类需要赋值json结构{"fileName": "your_file_name","fileUrl": "your_file_url"}， fileUrl支持本地文件、Base64、HTTP等三种协议的数据：
	•	本地临时文件协议（存储后删除）：tmpfile:/mindSynth/xxxx.docx
	•	本地持久文件协议：psfile:/mindSynth/xxxx.docx
	•	Base64数据流：data:xxxxx
	•	网络文件流协议：http://xxxx; https://xxxx

	•	支持在循环内使用嵌套对象和数组
5.6.3. 横向循环
格式： <hfor item in list>...</hfor>
用于在水平方向生成多列数据：
Plain Text<hfor item in demo.list2>{{item.var1}}  {{item.detail.var2}}</hfor>
特点：
	•	数据向右展开成多列
	•	适用于表头或横向数据展示
	•	循环变量 item 代表当前遍历的数据项
5.6.4. 图片插入
格式： {{@expression}}
在 Excel 形状中使用图片占位符：
Plain Text{{@imgurl1}}                // 静态图片{{@item.aaImage}}           // 循环中的动态图片{{@data.other.imgurl2}}     // 嵌套对象中的图片
支持的图片格式：
	•	URL图片：https://example.com/image.jpg
	•	Base64格式：data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAA...
图片处理特性：
	•	自动识别图片格式（PNG、JPEG）
	•	图片自动适应单元格大小
	•	支持在循环中动态插入图片
	•	保持原始形状的位置和尺寸信息
