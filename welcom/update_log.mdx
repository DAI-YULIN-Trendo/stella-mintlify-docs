<Update label="v1.9.7.0" description="12月01日 - 12月12日">
### 🚀 新機能と最適化

- **シングルサインオン（SSO）プロセス改造:** ログイン検証ロジックを最適化し、クロスシステムアクセスの利便性と本人認証のセキュリティを向上。
- **推奨質問機能ロジックの強化:** センシティブワードフィルタリング設定機能を追加し、必要に応じてセンシティブワードルールを設定できるようにし、推奨質問コンテンツのコンプライアンスを最適化。
- **コンポーネント拡張:** NL2SQLコンポーネントを追加し、自然言語からSQLクエリステートメントへの迅速な変換をサポートし、データベース操作の障壁を低減。
- **データベース互換性拡張:** 「Da Meng」データベースの適応サポートを追加し、プラットフォームのデータベース接続範囲を拡大。

### 🐛 バグ修正

- **エージェント対話帰属異常の修正:** 異なるエージェント間の対話クロストーク問題を解決し、エージェントAのチャットコンテンツは自身のみが応答することを確保し、エージェントBが他のエージェントの対話に誤って応答する状況を回避。
- **RAG VLモデル機能修正:** RAG VLモデルのビジュアル強化プロセス中にmodelIdが失われて強化が失敗する問題を修正し、ビジュアル強化機能の正常な実行を保障。
- **ドキュメントダウンロード形式最適化:** ドキュメントダウンロード後の構造の乱れやコンテンツレイアウト異常の問題を修正し、ダウンロードドキュメントの構造完全性と可読性を確保。
- **RAGモジュールExcel解析修正:** RAGモジュールにおけるExcelファイル解析が解析中の状態で停止する問題を修正し、Excelファイル解析プロセスのスムーズな完了を保障。
</Update>

<Update label="v1.9.6.0" description="11月17日 - 11月28日">
### 🚀 新機能と最適化

**ナレッジベース機能の強化**

- **データセットアップロード最適化:** 圧縮パッケージの自動解凍機能を追加し、圧縮パッケージ形式のデータセットのアップロードと自動解凍処理をサポートしました。
- **スライスフィルタリング機能:** コンテンツキーワードとスライス状態によるナレッジベーススライスのフィルタリングをサポートしました。
- **アップロード形式拡張:** ナレッジベースへの **XLS 形式ファイルのアップロード**をサポートしました。
- **画像処理強化:**「画像解析策」設定を追加し、画像コンテンツ認識と処理効果を最適化しました。
- **スライスプレビュー制御:** ナレッジベーススライスプレビュー時に「**全文表示**」または「**フラグメント表示**」モードの手動切り替えをサポートしました。
- **データセットスライス状態表示:** データセットスライスリストで、各スライスの解析状態を表示する機能を追加しました。

**コード生成とレンダリング**

- **コードブロック生成最適化:** コードブロック生成に対応する Prompt ロジックを最適化し、コード出力の正確性と標準性を向上させました。
- **ストリーミングレンダリング体験最適化:** ストリーミングレンダリングプロセス中のスクロールバーの応答ロジックを最適化し、スクロール異常を回避しました。

**エージェント機能**

- **履歴記録表示最適化:** Agent 公開後の履歴記録で、Excel ファイルを直接表示せず、対応する **JSON 形式データを表示**するように変更しました。
- **オープニングステートメント編集適応:** オープニングステートメント編集ポップアップの文字数制限を調整し、外側入力エリアと一致させました。
- **拡張質問設定最適化:** 拡張質問の Prompt を**設定可能モード**に変更しました。

**ユーザー体験**

- **チャットページ画像アップロード強化:** クリップボード経由でチャットページに直接画像をアップロードする機能をサポートしました。
- **テンプレートファイルダウンロード機能:** ドキュメント出力/Excel/PPT 生成ノードで、アップロード後の Excel/Word/PPT テンプレートファイルのダウンロード機能を追加しました。

### 🐛 バグ修正

- **対話表示修正:** 対話のゴースト問題を解決し、対話コンテンツの正確で重複のない表示を確保しました。
- **ドキュメント閲覧安定性修正:** PPTX、Word ファイル閲覧時に「次へ」をクリックすると時々ページクラッシュが発生する問題を修正しました。
- **マルチページログイン状態同期修正:** 同一ブラウザで複数のシステムインターフェースを開いている場合、1つのインターフェースのログアウトにより Token が無効になっても、他のインターフェースのログアウト時にシステムエラーを表示しないようにし、状態同期ロジックを最適化しました。
- **ロールデータ権限修正:** ロール作成時にカスタムデータ権限を追加する際、「すべて選択」をチェックしても実際にすべての権限が選択されない問題を解決しました。
- **ナレッジベース検索プロンプト修正:** ナレッジベース検索コンポーネントで、クエリ範囲として「すべてのファイル」を選択した場合でも「タグを選択してください」とプロンプトが表示される異常な問題を修正しました。
</Update>

<Update label="v1.9.5.0" description="11月01日 - 11月15日">
### 🚀 新機能と改善

**機能強化と拡張**

- **ナレッジベース検索機能の強化:** 知識ベースの検索リストをLLMに連携する際、**関連付けられたタグ情報も同時に送信**するようになりました。これにより、LLMにより完全なコンテキスト情報が提供され、応答の精度が向上します。
- **NL2SQL機能の拡張:** **外部データベースへの接続機能**を追加しました。これにより、データ利用の境界が広がり、より多くのデータソースから情報を抽出・分析できるようになりました。
- **ファイルアップロードメカニズムの最適化:** **アップロードファイルのモジュール別設定機能**を実装しました。業務ニーズに応じてモジュールごとに柔軟にアップロードルールを設定でき、設定の柔軟性が向上します。
- **システム設定機能のアップグレード:** **動的フォーム機能**を新たに追加しました。実際の業務シナリオに応じてシステム設定項目を迅速に調整でき、多様な設定ニーズに対応します。
- **コンポーネント構造の最適化:** コンポーネントの JSON 設定形式を「単一コンポーネント一行記述」モードに変更しました。これにより、設定ファイルの可読性と保守性が向上し、開発・デバッグが容易になります。

### 🐛 バグ修正とフィードバックの改善

- **ストリーミング出力の不具合修正:** 特定の利用環境（中国語シナリオ）におけるストリーミング出力時の**文字欠落のバグを完全に解消**し、テキスト伝送の完全性と正確性を確保しました。
- **MCP モジュールの適合性最適化:** MCP モジュールが MCP Server に接続する際に **Header 情報をサポートしないバグを解決**し、適合性の調整を完了しました。これにより、モジュール間の通信安定性が確保されます。

### 🛠️ ユーザー体験とパフーマンスの最適化

- **ストリーミングレンダリング体験の向上:** **ストリーミングレンダリング用バッファ機構**を導入し、コンテンツ読み込みの滑らかさを最適化しました。これにより、**スタッタリングが減少し**、ユーザーの閲覧・操作体験が向上します。
- **ページ切り替えロジックの最適化:** LLM の集約結果に切り替える際、**新しいタブ（またはウィンドウ）で開く**方式を採用しました。これにより、現在操作しているページが上書きされるのを防ぎ、ユーザーの操作の継続性が確保されます。

### 🔄 互換性の確保

- **旧バージョンの機能互換性:** 旧バージョンのエクスポート機能の互換性を改善しました。これにより、**アップグレード後も過去のエクスポート機能が正常に使用できる**ことが保証され、業務プロセスの連続性が維持されます。
</Update>
