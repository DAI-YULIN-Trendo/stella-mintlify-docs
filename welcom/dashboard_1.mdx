---
title: "ダッシュボード"
description: "Agent の利用状況や実行状況を確認するためのダッシュボード機能です。"
---

ダッシュボードでは、Agent の利用状況、実行状況、運用上の傾向を確認できます。公開後の Agent を継続的に改善するための観察ポイントとして活用します。

<CardGroup cols={2}>
  <Card title="利用状況の確認" icon="chart-line">
    利用回数、実行傾向、よく使われる Agent などを確認します。
  </Card>
  <Card title="改善ポイントの発見" icon="magnifying-glass">
    想定外の利用や失敗傾向を把握し、プロンプトやワークフロー改善につなげます。
  </Card>
</CardGroup>

## 確認するとよい項目

- Agent ごとの利用回数
- 実行成功 / 失敗の傾向
- よく利用される機能やリソース
- 改善が必要な入力パターン

<Info>
  ダッシュボードは公開後の運用改善に役立ちます。Agent を作成して終わりにせず、利用状況を見ながら継続的に調整してください。
</Info>
