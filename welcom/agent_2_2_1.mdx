**モジュール概要**

* ユーザーが自由に情報を入力できる機能です。入力内容は各ノードを通じシステムに送信されます（デフォルトで有効）。

### 🔌 入力とトリガー (Inputs & Triggers)

<CardGroup cols={2}>
  <Card title="条件をすべて満たした場合に動作を開始" icon="link">
    **タイプ**: ブール型
    
    本ノードは複数のブール型入力を接続可能。**全ての条件が `true`** の場合に本モジュールを実行します（AND条件）。
  </Card>
  <Card title="いずれかを満たした場合に動作を開始" icon="bolt">
    **タイプ**: ブール型
    
    本ノードは複数のブール型入力を接続可能。**いずれか1つでも条件が `true`** の場合に本モジュールを実行します（OR条件）。
  </Card>
</CardGroup>

### ⚙️ 設定 (Configuration)

<CardGroup cols={2}>
  <Card title="テキスト入力" icon="keyboard">
    **タイプ**: 文字列型
    
    ユーザーが自由にテキストを入力できる機能です。入力内容は「テキスト情報」ノードを通じシステムに送信されます（デフォルトで有効）。
  </Card>
  <Card title="ドキュメントアップロード" icon="file-arrow-up">
    **タイプ**: ブール型
    
    ユーザーがドキュメントをアップロードしての質問が可能になります。最大9個のファイルを同時アップロード可能（各最大50MB）。対応フォーマット：pdf,doc,docx,txt,ofd,xlsx,mp3,mp4,zip,csv。
  </Card>
  <Card title="画像アップロード" icon="image">
    **タイプ**: ブール型
    
    ユーザーが写真をアップロードして質問できるようにします。最大9つのファイルを同時にアップロード可能（各最大30MB）。PNG, JPG, JPEG形式をサポート。
  </Card>
  <Card title="ドキュメントレビュー" icon="file-contract">
    **タイプ**: ブール型
    
    「ドキュメントレビュー」モジュールと組み合わせて使用し、ドキュメント比較の有無の設定が可能になります。
  </Card>
</CardGroup>

### 📤 出力と動作 (Outputs & Behavior)

<CardGroup cols={2}>

  <Card title="テキスト情報" icon="keyboard">
    **タイプ**: 文字列型
    
    ユーザーが入力したテキスト情報が送信されます。
  </Card>
  <Card title="ドキュメント情報" icon="file-arrow-up">
    **タイプ**: ドキュメント型
    
    ユーザーがアップロードしたドキュメント情報が送信されます。
  </Card>
  <Card title="画像情報" icon="image">
    **タイプ**: 画像型    
    
    ユーザーがアップロードした画像情報が送信されます。
  </Card>
  <Card title="ボタンがクリックされていません" icon="hand-pointer">
    **タイプ**: ブール型
    
    ボタンがクリックされていない場合、出力値は `True` となります。
  </Card>
  <Card title="モジュール実行終了" icon="check-double">
    **タイプ**: ブール型
    **本モジュールの実行完了時、出力値は `True` となります**（通常、次処理を開始するためのトリガーとして使用）。
  </Card>
  <Card title="追加ボタン（ボタンカスタマイズ）" icon="hand-pointer">
    **タイプ**: ブール型
    **本モジュールの実行完了時、出力値は `True` となります**（通常、次処理を開始するためのトリガーとして使用）。
  </Card>
</CardGroup>
