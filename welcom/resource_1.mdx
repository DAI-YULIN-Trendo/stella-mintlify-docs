---

リソースは、Agent が外部情報や外部機能を利用するための管理領域です。ナレッジベース、データベース、ツール、MCP、スキルを整理しておくことで、ワークフローや Agentic モジュールから安定して呼び出せます。

<CardGroup cols={2}>
  <Card title="ナレッジベース" icon="book-open" href="/welcom/knowledgebase_1">
    社内文書、FAQ、業務手順など、参照用の知識を管理します。
  </Card>
  <Card title="データベース" icon="database" href="/welcom/database_1">
    業務データの検索、追加、更新、削除に利用します。
  </Card>
  <Card title="ツール" icon="wrench" href="/welcom/agent_2_4">
    外部 API や公式ツールを Agent から呼び出します。
  </Card>
  <Card title="MCP管理" icon="cube" href="/welcom/mcp_1">
    MCP Server を接続し、標準化されたツール呼び出しを管理します。
  </Card>
  <Card title="スキル管理" icon="wand-magic-sparkles" href="/welcom/skill_1">
    再利用可能な処理能力や手順をスキルとして管理します。
  </Card>
</CardGroup>

## Agentic との関係

Agentic モジュールでは、これらのリソースを組み合わせてタスクを実行できます。ナレッジベースで根拠を取得し、ツールや MCP で外部処理を行い、スキルで定型化された手順を呼び出すことで、より実務に近い Agent を構築できます。
