---
title: "MCP管理"
description: "MCP Server を接続し、Agent から外部ツールやサービスを利用するための管理機能です。"
---

MCP管理では、MCP Server を登録し、Agent から外部ツールやサービスを呼び出せるようにします。標準化されたプロトコルでツールを接続することで、複数の Agent から同じリソースを再利用しやすくなります。

<CardGroup cols={2}>
  <Card title="MCP Server の登録" icon="cube">
    接続先、認証情報、利用可能なツールを管理します。
  </Card>
  <Card title="Agent からの呼び出し" icon="robot">
    Agentic やワークフロー内のツール呼び出しから MCP を利用できます。
  </Card>
</CardGroup>

## 利用時の確認ポイント

- 接続先 URL と認証情報が正しいか
- Agent に必要なツールのみを公開しているか
- 本番利用前にテスト呼び出しが成功するか
- 外部サービスへ送信するデータ範囲が適切か

<Info>
  MCP は外部システムとの接続口になります。権限、認証、送信データの扱いを事前に確認してください。
</Info>
