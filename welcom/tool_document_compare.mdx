---

ドキュメント比較ツールは、複数の文書を指定した観点で比較し、条件を満たしているかを確認するための公式ツールです。契約書、申請書、仕様書、社内文書など、差分確認や条件チェックが必要な業務に利用できます。

## 使いどころ

<CardGroup cols={2}>
  <Card title="条件チェック" icon="circle-check">
    文書が指定された条件、規程、チェック項目を満たしているか確認します。
  </Card>
  <Card title="複数文書の比較" icon="file-diff">
    複数の文書間で内容の差分や整合性を確認します。
  </Card>
  <Card title="レビュー業務の効率化" icon="clipboard-check">
    人手で確認していた文書レビューの初期確認を自動化できます。
  </Card>
  <Card title="Agent 連携" icon="robot">
    比較結果を Agent の後続処理に渡し、要約や改善提案を生成できます。
  </Card>
</CardGroup>

## 基本フロー

<Steps>
  <Step title="公式ツールから選択する">
    「ツール」>「公式ツール」からドキュメント比較ツールを開きます。
  </Step>
  <Step title="比較対象を指定する">
    比較する文書、確認条件、必要に応じて基準文書を指定します。
  </Step>
  <Step title="比較を実行する">
    ツールが文書内容を解析し、指定条件に基づいて確認します。
  </Step>
  <Step title="結果を活用する">
    比較結果を確認し、必要に応じて Agent の回答生成、通知、保存処理へ接続します。
  </Step>
</Steps>

<Info>
  ワークフロー内で文書アップロードを扱う場合は、基本モジュールの [ドキュメントのレビュー](/welcom/agent_2_2_6) や [ドキュメントクエリ](/welcom/agent_2_2_8) と組み合わせて設計できます。
</Info>

## 設計ポイント

- 比較対象の文書形式を事前に確認する
- 判定条件を曖昧にせず、チェック項目として整理する
- 差分確認だけでなく、条件を満たさない箇所の説明も出力する
- 本番利用前に代表的な文書でテストする
