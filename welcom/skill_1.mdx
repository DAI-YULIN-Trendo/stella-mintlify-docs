---
title: "スキル管理"
description: "Agent から再利用できる処理能力や業務手順をスキルとして管理します。"
---

スキル管理では、Agent から再利用できる処理能力、業務手順、外部連携のまとまりを管理します。複数の Agent で同じ処理を使う場合、スキルとして整理しておくことで設定の重複を減らせます。

<CardGroup cols={2}>
  <Card title="再利用性" icon="repeat">
    複数 Agent で共通する処理や業務手順を再利用できます。
  </Card>
  <Card title="Agentic 連携" icon="robot">
    Agentic モジュールから必要に応じてスキルを呼び出せます。
  </Card>
</CardGroup>

## 管理のポイント

- スキル名と説明を分かりやすく設定する
- 入力と出力の形式を明確にする
- 利用対象の Agent や権限を整理する
- 更新時は影響する Agent を確認する

<Tip>
  よく使う業務処理は、ワークフローへ直接作り込む前にスキル化できるか検討すると、保守しやすくなります。
</Tip>
